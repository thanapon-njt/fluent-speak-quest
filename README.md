# Fluent Journey

Create a modern responsive web application UI for an AI-powered English speaking learning platform.

The app helps users become fluent in spoken English within 1 year through gamified chapters, vocabulary learning, grammar practice, speaking exercises, and AI conversation roleplay.

Modern SaaS + Duolingo-inspired gamification
Minimal but immersive
Mobile-first responsive design
Clean typography
Rounded cards and soft shadows
Professional but motivating

Accent: yellow for XP/rewards

Success states should feel rewarding
